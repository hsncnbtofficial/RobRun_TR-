# Rob Run — Türkçe terim sözlüğü (tutarlılık için)

## Kurallar
- `<color=...>`, `</color>`, `<link=...>`, `{0}`, `{0:...}`, `{:palette(Main)}`, `\n` AYNEN korunur. Etiketlerin içindeki metin çevrilir.
- SmartFormat: `{0:plural:{} item|{} items}` → `{0:plural:{} eşya|{} eşya}` (yapı aynı kalır, sadece kelimeler).
- `{0:cond:...}`, `{0:choose(...):a|b}` gibi seçenekler: seçenek kelimeleri çevrilir, ayraçlar/koşullar korunur.
- Hitap: "sen" değil resmi olmayan ama saygılı oyun dili → arayüzde emir kipi ("Satın al", "Kilidi aç"), açıklamalarda "-abilirsiniz/-ebilirsin" yerine kısa ve doğal: "…yapabilirsin". → KARAR: **sen** dili (oyun samimi/argolu bir dünya).
- Diyaloglar (NPC konuşmaları): samimi, sokak ağzına yakın, doğal Türkçe.
- Özel isimler çevrilmez: ROB RUN, Lenny, Looty, Sunny Bay, Kefir, Steam, Discord, marka/silah model adları (MK, PDW-90, AP Scalar…).
- Büyük harfe çevrilen başlıklar için sorun yok (fontlarda İ/Ş/Ğ var).
- Kısa buton metinleri kısa kalmalı (UI taşmasın).
